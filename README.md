# TaksFlow

TaksFlow é um aplicativo simples de lista de tarefas criado com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Persistência local usando `localStorage`

## Como usar

1. Abra o arquivo `index.html` no seu navegador.
2. Digite a tarefa no campo de entrada.
3. Clique em `Adicionar` ou pressione `Enter`.
4. Use o botão ✓ para marcar uma tarefa como concluída.
5. Use o botão X para excluir uma tarefa.

## Estrutura do projeto

- `index.html` - marcação do aplicativo
- `style.css` - estilos visuais
- `script.js` - lógica de tarefas e armazenamento local

## Observações

- As tarefas são salvas no navegador, então elas permanecem mesmo após recarregar a página.
- O app funciona melhor em navegadores modernos.
